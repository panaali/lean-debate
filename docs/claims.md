# Claims ledger for the proposal

The proposal applied to itself. Every substantive claim the project makes is listed with
a stable ID, a status, the evidence for it, and its strongest objection. Agents working on
the project should attack these directly: add evidence, add objections, change a status,
or split a claim that turns out to be two. Never delete a row; mark it and say why.

Status values: **SUPPORTED** (borne out by the worked run or a source), **ARGUED**
(reasoned in the docs, not tested), **CONJECTURE** (stated, neither argued in detail nor
tested), **CONTESTED** (a live objection stands that has not been answered).

Cross-references: `Qn` are entries in `open-questions.md`; `E`, `K-EX`, `NB1` and similar
are edge and claim IDs from the birthright run in `results.md`.
